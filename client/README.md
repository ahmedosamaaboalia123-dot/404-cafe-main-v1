# 404 Project

A React frontend-only project built with Vite.

## Tech Stack

- React 19
- Vite 6
- React Router DOM 7
- TanStack Query 5
- Zustand 5
- Axios
- React Hook Form + Zod
- Recharts
- date-fns
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` — start dev server
- `npm run build` — production build
- `npm run preview` — preview production build
