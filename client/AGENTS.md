# Project Rules & Instructions

## Core Principles
1. **Responsive & Mobile-First Design (أولوية الموبايل والتجاوب الكامل)**:
   - All components, views, modals, forms, and tables must be fully responsive across all screen sizes (mobile, tablet, desktop).
   - Mobile UX is the highest priority:
     - Touch targets must be at least 44px on mobile screens.
     - Sidebars, headers, navigation, cards, forms, tables, and dialogs must render cleanly without overflow or broken layouts on mobile screens.
     - Full support for Arabic RTL layout and mobile ergonomics.
